# 🎓 Student Performance & Remedial Analyzer

A full-stack Academic Management Portal built with **Python (Flask)** and **NumPy**. This system automates the tracking of student marks and identifies "Slow Learners" for remedial support.

### 🚀 Key Features
- **AI-Driven Trends:** Uses academic data to visualize student performance.
- **Secure Dual-Portal:** Strictly separated login systems for Staff and Students.
- **Automated Remedial Workflow:** Identifies students scoring below 50% for mandatory retests.
- **Cross-Platform:** Designed to run easily on any system without complex setup.

### 🛠️ Tech Stack
- **Backend:** Python 3.x, Flask
- **Database:** SQLite3
- **Analysis:** NumPy, Pickle
- **Frontend:** HTML5, CSS3 (Professional Academic Theme)
